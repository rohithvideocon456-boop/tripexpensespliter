# TripSplit Pro — Trip Expense Splitter

A complete BCA-friendly trip expense management project built with HTML, CSS and JavaScript. It uses browser localStorage, so no server or database is required.

## Features
- Login, registration and demo password reset
- Multiple trips with destination, dates and budget
- Add/remove trip members
- Add/edit/delete expenses
- Categories: Food, Hotel, Transport, Tickets, Shopping and Other
- Equal/custom participant selection per expense
- Receipt image upload stored locally
- Notes on expenses
- Dashboard with budget, totals and charts
- Smart minimum-payment settlements
- Settlement history
- Expense search/filter
- CSV export
- Print / Save as PDF trip report
- User profile and currency display (INR, USD, EUR, GBP, AED)
- Dark/light mode
- Responsive mobile layout

## Run
1. Extract the ZIP.
2. Open the `trip-expense-splitter` folder in VS Code.
3. Open `index.html` with Live Server, or double-click it in a browser.
4. Create an account or use any email + a password of 4+ characters for the demo login.

## Important
This is a frontend/localStorage college project. The login is not a production authentication system. Passwords and data are stored in the browser and should not be used for real accounts.
